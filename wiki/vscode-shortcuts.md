# VS Code Keyboard Shortcuts Quick Reference

| Action                        | Shortcut (Linux/Windows) | Shortcut (Mac)      |
|-------------------------------|:------------------------:|:-------------------:|
| Command Palette               | Ctrl+Shift+P             | Cmd+Shift+P         |
| Keyboard Shortcuts Reference  | Ctrl+K Ctrl+S            | Cmd+K Cmd+S         |
| Open Markdown Preview         | Ctrl+Shift+V             | Cmd+Shift+V         |
| Split Editor                  | Ctrl+\                   | Cmd+\               |
| Side-by-side Markdown Preview | Ctrl+K V                  | Cmd+K V             |
| Toggle Terminal               | Ctrl+`                   | Ctrl+`              |
| Find                          | Ctrl+F                   | Cmd+F               |
| Replace                       | Ctrl+H                   | Cmd+Option+F        |
| Go to File                    | Ctrl+P                   | Cmd+P               |
| Go to Line                    | Ctrl+G                   | Cmd+G               |
| Save                          | Ctrl+S                   | Cmd+S               |
| Close Editor                  | Ctrl+W                   | Cmd+W               |
| Undo                          | Ctrl+Z                   | Cmd+Z               |
| Redo                          | Ctrl+Y / Ctrl+Shift+Z    | Cmd+Shift+Z         |

**Tip:** You can customize shortcuts in File > Preferences > Keyboard Shortcuts.
